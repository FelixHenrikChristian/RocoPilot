# 奇遇赛季流程记录

本文记录《洛克王国世界》不同赛季奇遇事件的游戏流程，以及 RocoPilot 对应的自动识别方式。赛季配置位于 `RocoPilot/Configuration/EncounterSeasons/seasons.json`。

## 通用规则

- 异色提示独立于赛季机制：识别到“发现异色精灵”后，RocoPilot 会暂停本场自动操作，并把识别结果放入待确认队列。
- 待确认异色需要用户在“统计”页确认。确认后计入异色统计，并按确认时的精灵名清空对应赛季奇遇计数。
- 精灵名 OCR 结果需要经过图鉴匹配。为避免空识别或明显误识别被硬匹配到最接近精灵，自动统计会使用 `spiritNameMatchThreshold` 作为最低相似度门槛。
- 奇遇和异色最终按图鉴进化链最低阶归一记录。
- 每个赛季的奇遇计数彼此独立。赛季更新后，旧赛季的保底池不继承到新赛季；新赛季刷出的事件只写入当前赛季数据。

## S1 赛季：污染（2025/3/26-2025/5/21）

### 游戏流程

1. 玩家丢精灵球捕捉精灵。
2. 地图上概率出现污染精灵，可能属于当前捕捉精灵家族，也可能是随机刷出的其他精灵。
3. 进入战斗时，目标精灵处于污染状态。
4. 第一层血条被打空后，污染褪去，顶部出现“噩梦力量的保护解除，捕捉功能已恢复”一类文字提示。
5. 精灵名称区域恢复为可统计的真实精灵名。

### 识别方式

- 配置项：`detectionMode = "TipText"`。
- RocoPilot 每秒 OCR `battle-tip` 区域。
- OCR 文本与当前赛季 `tipText` 的相似度达到 `matchThreshold` 后，判定为本场奇遇已解除。
- 判定成功后 OCR `battle-enemy-name` 区域，并用图鉴匹配出的精灵名计数 +1。

## S2 赛季：狂欢（2025/5/22-2025/7/15）

### 游戏流程

1. 玩家丢精灵球捕捉精灵。
2. 地图上概率出现 3 个“幸运惊喜盒”。
3. 玩家选择其中一个进入战斗。
4. 第一层血条被打空前，敌方名称显示为“幸运惊喜盒”。
5. 第一层血条被打空后播放动画，没有顶部解除文字提示。
6. 动画结束后，敌方名称从“幸运惊喜盒”恢复为真实精灵名。

S2 仍可能低概率刷出 S1 形式的污染精灵。虽然解除流程与 S1 相同，但它属于 S2 的保底池，应计入 S2 赛季数据，而不是回写到 S1。

### 识别方式

- 统计类型名：`encounterTypeName = "狂欢"`。幸运惊喜盒是本赛季主要机制，不直接作为统计卡片标题。
- 配置项：`detectionMode = "EnemyNameTransition"`，并保留 S1 污染解除 `tipText` 作为同赛季兜底入口。
- RocoPilot 每秒 OCR `battle-enemy-name` 区域，优先识别幸运惊喜盒流程。
- 当 OCR 名称与 `placeholderName`（默认“幸运惊喜盒”）达到 `placeholderMatchThreshold` 时，记录“本场战斗已见到惊喜盒”。
- 后续同一场战斗中，如果敌方名称不再匹配“幸运惊喜盒”，且能通过图鉴匹配到相似度不低于 `spiritNameMatchThreshold` 的真实精灵名，则判定 S2 奇遇解除，并给该精灵计数 +1。
- 如果未命中幸运惊喜盒名称变化，会继续 OCR `battle-tip` 区域；当污染解除提示与 `tipText` 达到 `matchThreshold` 时，也按 S2 赛季计数 +1。
- 该判定也会触发自动战斗的“奇遇解除后操作”状态。

### 暂不支持

- “狂欢时刻”触发时，接近幸运惊喜盒不会进入战斗，盒子会在大世界自动打开，精灵直接出现在地图上。
- 当前没有稳定的战斗内名称变化或顶部解除提示可用，因此 RocoPilot 暂不自动统计这类情况。
- 如果发生狂欢时刻奇遇，当前建议在“统计”页手动新增对应精灵奇遇。
- 后续可以考虑 OCR 狂欢时刻相关提示，但它只能作为辅助提醒，不能直接确认具体盒子内的精灵名称。
