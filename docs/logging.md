# 运行日志

在「设置 → 文件目录 → 日志目录」打开对应日期的文件。每条记录包含时间、级别和来源。应用按天滚动日志，最多保留 14 个文件。

| 级别 | 何时记录 | 示例 |
| --- | --- | --- |
| Debug | 开发时需要的技术细节，输出到调试器 | 分辨率映射、场景变化、一次点击的坐标 |
| Information | 已发生的操作与结果 | 任务开始、实际发送的按键、挑战完成次数、取消、统计上传成功 |
| Warning | 可继续运行的故障，写明受影响的功能 | 模板缺失、挑战失败后重试、通知发送失败 |
| Error / Fatal | 操作异常终止 / 应用未处理异常 | 独立任务异常退出、应用崩溃 |

在知道操作结果的一层写日志。按键发送返回后记录实际序列，数据保存成功后记录结果。异常作为异常参数传入；消息使用命名占位符，带上任务、回合或其他必要上下文。界面负责向用户显示原因。

正常的轮询等待、模板未命中和逐帧 OCR 原文无需写入文件。识别调试可使用识别遮罩。使用业务状态变化或已执行的动作作为记录时机，不为折叠日志维护指纹、计数器和锁。日志参数中不执行状态更新。

### 各功能的记录时机

| 功能 | 文件日志中应能找到的事件 |
| --- | --- |
| 应用、更新 | 启动版本与运行环境、手动检查的结果、发现新版、更新源请求失败时的 HTTP 状态、正常关闭或未处理异常。 |
| 实时任务、快捷键 | 会话启动时的目标窗口、分辨率、截图与输入方式；挂起、恢复、停止；快捷键实际改变的功能状态或保存的截图路径。 |
| 自动战斗、奇遇 | 本回合实际发送的按键、换宠结果、技能失败原因、触发异色保护、截图落盘、统计暂存或计数成功。 |
| 独立任务、每日清单 | 当前子任务和清单序号、挑战成功次数、连续失败重试、扫描结果、完成、取消或异常终止。 |
| 统计、云同步、图鉴 | 统计账号确认状态、数据下载合并或上传结果、图鉴同步数量，失败的操作与异常。 |
| 设置、通知、遮罩 | 配置文件加载失败时的路径、保存失败的设置、通知发送或遮罩显示失败。 |
