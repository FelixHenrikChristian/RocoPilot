# RocoPilot 0.5.0.0

## 🎉 特性：

- **S5 圣龙奇遇**：更新当前赛季为 S5，统计日期为 2026 年 11 月 5 日至 12 月 30 日。
- **新赛季统计**：赛季配置过期后，奇遇和异色记录进入暂存；更新配置后，可核对精灵名、奇遇次数和目标赛季，选择要计入的数据，未选择的数据继续保留。
- **截图热键**：热键页新增“基础功能 → 截图”，游戏在前台时可快捷保存游戏画面，无需启动实时任务。图片以时间戳命名，保存至安装目录下的 `Screenshots` 文件夹。
- **云同步冲突核对**：同一账号在多台设备产生冲突时，可核对两端统计并选择保留本地或采用云端。

## ✨ 优化：

- **精灵图鉴**：同步至 493 个编号、662 种形态，补充 S5 精灵、普通与异色头像及进化链。
- **自动战斗**：不再等待精灵名识别完成后才执行战斗操作，名称识别在后台继续进行。
- **传说挑战**：移除已下线的银月狼王默认选项，保留圣羽翼王、龙息帕尔，以及刷新游戏名单功能。
- **界面与目录**：设置页将日志和截图目录整合到“文件目录”折叠面板；优化新赛季统计确认布局，统一弹窗控件底色，并更新官网使用文档。

## 🔧 修复：

- **挑战流程**：修复没有传说印记、仅显示居中契约印记卡片时捕捉确认卡住的问题；支持处理队伍不足时的助战确认弹窗，并调整捕捉后的奖励关闭与结算确认流程。
- **统计记录**：修复切换账号后编辑、删除目标不正确，以及开启统计、停止任务时旧识别结果回写的问题；保存失败时保留数据以便重试。
- **云同步**：修复统计升级后误判旧版云端冲突的问题，完善计数清零、删除、导入及暂存归档后的同步，避免旧快照恢复已处理数据。
- **图鉴同步**：跳过源站明确标记的未知占位卡，修复占位内容导致整次同步失败的问题。
- **日志显示**：修复筛选和重新进入日志页时重复追加记录的问题。

## ⚠️ 注意：

- 更新赛季配置不会自动计入此前暂存的数据，请在统计页核对并确认归入 S5。
- 多设备使用云同步时，请先将各端更新到新版本；冲突选择以整个账号为单位，不会自动相加两端记录，确认前请核对并按需导出备份。
