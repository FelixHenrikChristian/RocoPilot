# 统计数据 Cloudflare R2 同步教程

Cloudflare R2 使用 S3 兼容 API。RocoPilot 会把统计文件保存为 `RocoPilot/statistics.json`，界面里只需要填写必要的连接信息。

## 1. 创建 R2 Bucket

1. 登录 Cloudflare Dashboard。
2. 进入 R2。
3. 创建一个 Bucket，例如 `roco-pilot`。
4. 记下当前账户的 Account ID。

Cloudflare R2 免费层包含 10 GB-month 存储、每月 100 万次 Class A 请求和 1000 万次 Class B 请求。统计同步只写入一个 JSON 文件，正常使用量很低。

## 2. 创建 R2 API 令牌

1. 在 R2 页面进入“Manage R2 API tokens”。
2. 创建一个 API Token。
3. 权限选择可读写对象的权限。
4. 作用范围选择刚创建的 Bucket。
5. 复制生成的 `Access Key ID` 和 `Secret Access Key`。

`Secret Access Key` 只显示一次，不要泄露给他人。

## 3. 在 RocoPilot 填写云同步设置

1. 打开“统计”页面。
2. 点击右上角“设置”。
3. 选择“云同步设置”。
4. 同步方式选择“Cloudflare R2”。
5. 填写 Account ID、Bucket、Access Key ID 和 Secret Access Key。
6. 打开“启用同步”。
7. 点击“保存”，再点击“测试连接”。

首次使用时，如果云端还没有统计文件，可以点击“上传”，把当前本地统计写入 R2。如果云端已经有其他设备的数据，应用会在启动检查或上传前先下载并合并，不需要再手动执行固定顺序。

## 4. 自动同步行为

开启云同步后，本地统计数据发生变化会延迟约 8 秒自动上传。连续多次变化只会上传最后一次结果。

应用启动后会检查一次云端版本；如果云端已被其他设备更新，会先下载并同步到本地。每次手动或自动上传前也会再次检查，发现新版本时先合并，再继续上传。

奇遇按账号、赛季、精灵累计总数，不保存逐次流水。确认异色时保存出异色前的次数，并在同一次本地保存中清空对应奇遇计数。

每个账号保留各设备的最新修改版本。后续版本替换整个账号快照，清零、减少次数、删除记录和确认或忽略异色都会一起同步；不同账号可以分别采用各自的新版本。删除整个账号后仅保留 UID 和版本标记，防止离线设备把旧记录带回来。重新添加同一 UID 会继承删除前的版本，从空记录重新开始。导入备份会保留已有删除标记，并将备份中省略的现有账号标为删除。

同一账号两端各自修改时，会保留双方数据并停止本次同步，不会相加次数、取最大值或默认覆盖。打开云同步窗口点击“上传到云端”或“合并云端数据”，核对该账号的奇遇、异色、暂存和删除状态后，选择“保留本地”或“采用云端”。选择以整个账号为单位；取消可先导出备份或修改本地内容。确认时会重新检查两端，期间发生变化就要求重新核对。决议保存双方的版本后再上传；网络失败后可重试，不会重复计数。

状态显示“待上传”时，本地修改尚未成功上传；同步失败时显示错误。重启后会继续安排未上传的数据，即使云端版本没有变化。换设备前请确认上传成功。

统计文档格式升级为 3.0，旧文档在载入时迁移；升级前已删除但尚未同步的账号，会根据已保存的同步基线补上删除标记。无法证明先后关系的旧数据需要核对选择。所有参与同步的设备都应升级到支持本机制的版本，旧客户端不理解账号删除标记。

上传使用 R2 条件写入。即使另一台设备恰好在“检查完成”和“上传开始”之间更新了文件，本次写入也会被 R2 拒绝，RocoPilot 会重新下载合并并重试，避免检查与上传之间的竞态覆盖。

## 5. 常见问题

### 403 或签名错误

检查 Account ID、Access Key ID 和 Secret Access Key 是否填写正确，并确认 API Token 有目标 Bucket 的对象读写权限。

### 404 或云端暂无统计数据

如果还没有上传过统计文件，这是正常状态。点击“上传”后会生成 `RocoPilot/statistics.json`。

### 换设备

先在原设备确认上传成功，并将两台设备都升级到支持账号版本的版本。在新设备上填写同一个 Cloudflare R2 配置并启用同步。重新启动应用后会自动检查并下载云端数据；也可以直接点击“上传”，上传前会自动完成同样的检查与合并。
