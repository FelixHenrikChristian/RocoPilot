# FAQ

## 为什么会请求管理员权限？

为实现模拟鼠标点击，依赖Interception驱动注入，该方式需要管理员权限。

## 截图或识别不正常怎么办？

1. 开启“显示识别区域”，检查游戏分辨率、画面比例与 UI 缩放。
2. 优先使用 `2048×1152`（16:9）或 `1920×1440`（4:3）素材基准分辨率。
3. 保持游戏可见；切换截图方式后重新启动任务。
4. 在日志中检查截图、窗口绑定、OCR 和图像识别信息。

## 奇遇没有计数怎么办？

检查启动页任务与“奇遇计数”开关，再查看统计页是否有待确认 UID。账号未确认时暂停入账，不会沿用默认账号。

账号确认后，检查游戏是否出现有效奇遇解除信号、名称是否识别成功，并同步图鉴。软件内赛季配置到期后，记录会显示在“新赛季”暂存中。

## 切换统计账号会改变自动记录对象吗？

统计页账号切换用于浏览，本次自动记录使用启动或开启计数时确认的账号。存在待确认请求时，可点击正确账号完成确认。切换游戏账号后，应停止并重新启动任务，重新核对 UID。

## UID 识别失败后怎么办？

到统计页重新识别或手动输入并确认 UID；也可在待确认时点击正确的已有账号。确认前暂停自动入账，应用与信息遮罩会显示提醒。

## 自动战斗没有按键怎么办？

1. 检查启动页任务和“实时”页的自动战斗开关。
2. 在“启动”页确认输入方式为 `Interception`，驱动已安装且安装后已重启电脑。
3. 保持游戏前台，核对普通战斗释放顺序。
4. 查看是否因异色保护暂停本场操作，并检查日志中的识别与按键记录。

## 挑战次数为什么没有增加，或者提前结束？

次数按成功捕捉累计，失败不增加，连续失败 3 次会停止。传说挑战遇到体力或周次数不足且未启用传说印记，或缺少所需专属印记时，也会停止并提示。结合任务结果与日志核对原因。

## 待确认异色为什么不会自动计入？

识别可能受 OCR、遮挡和画面状态影响。需在统计页核对名称和奇遇次数，再确认捕获；确认后才写入异色并清零对应奇遇累计。误识别可忽略。

## 赛季更新前的统计会记到哪里？

软件内赛季配置到期后，新记录进入“新赛季”暂存，奇遇按日期累计，页面按精灵展示。图鉴无法精确匹配时保留原始识别文字。

临时异色可先确认捕获并清零对应累计。更新软件或同步图鉴后，点击“确认新赛季统计”，按“精灵＋建议赛季”核对，修改名称、次数和目标赛季后归档。确认后删除对应暂存，未处理的继续保留；异色归档不会再次清零奇遇。没有可选目标赛季时等待软件的赛季配置更新。

## 云同步会覆盖本地数据吗？

同步按账号比较版本，后续版本替换旧版本，清零、删除、异色确认等修改也会同步。

同一账号两端各自修改时，停止本次同步并保留双方数据。打开云同步窗口点击“上传到云端”或“合并云端数据”，核对后选择“保留本地”或“采用云端”。选择保留整个账号版本，另一端独有的内容不会自动相加；取消可先分别导出备份或修改本地记录。

换设备前确认上传成功，所有设备均升级到支持当前同步机制的版本。“待上传”表示本地修改尚未成功上传，错误详情可在同步窗口和日志中查看。

## 没有收到 Windows 通知怎么办？

在“通知”页确认 Windows 通知已开启，发送测试通知；检查系统通知权限、勿扰模式以及 RocoPilot 日志。提示音可独立开关。

启用通知后，实时异色提醒会保存并附带游戏截图，目录为 `%LOCALAPPDATA%\RocoPilot\Screenshots\Shiny`。关闭通知时不保存此类截图；通知失败不影响异色保护和待确认记录。

## 恢复设置会删除统计数据吗？

会。“恢复设置”会清除用户偏好、统计记录和云同步配置，随后退出应用。请先在统计页导出重要数据。重新启动后需重新配置；如果保留了云端数据，可重新配置同步后取回。

## 日志在哪里？

“日志”页文件按钮可打开当天日志，没有当天文件时打开目录；“设置”页“日志文件”可直接打开目录。
