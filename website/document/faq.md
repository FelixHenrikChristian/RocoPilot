# FAQ

## GitHub 下载慢怎么办？

下载页提供两个来源：

- `Cloudflare R2`
- `GitHub Release`

如果 GitHub 访问较慢，可以优先使用 Cloudflare R2。两个来源提供的是同一个安装包。

## 为什么会请求管理员权限？

RocoPilot 默认会以管理员方式启动。它需要截图、识别窗口并模拟按键，管理员权限可以减少截图失败、窗口识别失败或按键不生效的情况。

如果遇到相关问题，可以优先查看日志：

- 截图失败或窗口绑定失败。
- 自动战斗没有按键。
- 日志提示目标窗口权限不足。

## 截图或识别不正常怎么办？

可以按顺序检查：

1. 在“启动”页开启 `显示识别区域`。
2. 确认游戏窗口位置和尺寸没有明显异常。
3. 切换 `截图方式` 后重新启动实时任务。
4. 切换 `OCR 识别方法` 后观察识别效果。
5. 进入“日志”页搜索截图、OCR 或识别相关记录。

## 奇遇没有计数怎么办？

常见原因：

- 实时任务未启动。
- `奇遇计数` 开关未开启。
- 当前赛季信息不符合预期。
- OCR 或图像识别没有识别到有效名称。
- 图鉴数据未同步，名称匹配效果较差。

建议先同步图鉴数据，再打开日志查看识别结果。

## 自动战斗没有按键怎么办？

可以按顺序检查：

1. 确认实时任务已启动。
2. 确认 `自动战斗` 开关已开启。
3. 确认游戏窗口在前台。
4. 尝试切换 `按键输入方式`。
5. 如果使用 `Interception`，确认驱动已安装并重启电脑。
6. 查看日志中的战斗识别和按键发送记录。

## Interception 是必须的吗？

不是必须。RocoPilot 提供多个按键输入方式：

- `PostMessage`
- `SendInput`
- `Interception`

如果普通输入方式在你的环境中无法生效，再考虑使用 Interception。

## 待确认异色为什么不会自动计入？

异色识别可能受 OCR、画面遮挡和识别区域影响。RocoPilot 会先把结果放入待确认队列，避免误识别直接污染统计。

确认前可以修改：

- `精灵名`
- `当前奇遇计数`

确认后才会写入异色统计，并重置对应精灵的当前赛季奇遇计数。

## 云同步会覆盖本地数据吗？

云同步窗口提供 `刷新`、`上传` 和 `合并`。

- `上传`：先检查并合并云端新版本，再把当前本地统计上传到云端。
- `合并`：根据上次同步状态，把云端统计合并到本地记录。
- `刷新`：查看云端更新时间。

启用同步后，应用启动时会自动检查云端；上传前也会再次检查，并通过条件写入避免另一台设备在检查后抢先更新造成覆盖。不同账号可以分别保留各自设备上的修改；同一账号请避免在两台设备同时修改。

## 恢复设置会删除统计数据吗？

“恢复设置”用于清除用户偏好并重启应用。执行前仍建议先导出或同步重要统计数据。

如果只是想备份统计数据，请在“统计”页使用 `导出数据`。

## 日志在哪里？

有两个入口：

- `日志` 页右上角文件按钮：打开当天日志文件。
- `设置` 页“日志文件”：打开日志所在目录。

提交问题反馈时，建议附上相关时间段的日志内容，并说明当时使用的截图方式、OCR 方法和目标功能。
