# 功能

本页按功能说明 RocoPilot 的主要配置项。点击配置项名称可展开详细说明。

## 启动页

![启动页配置](/screenshots/launch-options.png)

### 启动任务

::: details 截图方式
选择实时截图任务使用的捕获后端。

- `Windows Graphics Capture`：高性能实时截图方式，通常作为首选。
- `BitBlt`：传统 GDI 兼容模式，适合在首选方式无法正常截图时尝试。
- `PrintWindow`：尝试进行窗口后台截图，适合作为兼容方案。
:::

::: details OCR 识别方法
选择所有 OCR 任务使用的文字识别后端。

- `PaddleOCR PP-OCRv5`：本地中英文 OCR 模型，适合作为常用选择。
- `Windows OCR`：使用 Windows 系统 OCR 能力，依赖系统可用语言包。
- `Tesseract OCR 5`：本地离线 OCR 方案，识别效果一般。
:::

::: details 显示识别区域
开启后，RocoPilot 会在游戏画面上叠加图像匹配和 OCR 的识别区域框，便于检查识别范围。
:::

### 信息遮罩窗口

信息遮罩用于显示当前状态、奇遇计数、识别结果和待确认异色提示。

::: details 锁定位置
开启后固定信息遮罩窗口的位置；关闭后可以拖动窗口。
:::

::: details 重置位置
将信息遮罩窗口恢复到游戏窗口右侧附着的默认位置。
:::

## 实时页

### 奇遇计数

::: details 图鉴源

:::

::: details 精灵图鉴
打开图鉴窗口，查看当前图鉴源提供的精灵头像、名称、变种和进化链等数据。
:::

::: details 同步图鉴数据
手动同步当前图鉴源的数据。
:::

### 自动战斗


::: details 奇遇解除操作
选择识别到奇遇解除后的后续动作。

- `无操作`：识别到奇遇解除后不再按键，等待手动释放技能。
- `回能`：识别到奇遇解除后只按 X 回能，直到退出战斗。
- `战技`：奇遇解除前后，始终按战斗配置释放技能。
- `捕捉`：识别到奇遇解除后，释放捕捉序列，直到战斗结束。
:::

::: details 按键输入方式
选择自动战斗向游戏发送按键的方式。

- `PostMessage`：旧的后台窗口消息方式；不要求游戏前台，但已经被游戏屏蔽。
- `SendInput`：Windows 扫描码输入；需要游戏窗口前台，也已经被游戏屏蔽。
- `Interception`：驱动级键盘输入；需要安装 Interception 驱动并重启，游戏窗口需处于前台。
:::

::: details 战斗配置
打开自动战斗配置窗口，设置技能释放顺序和单回合按键序列。

![战斗配置窗口](/screenshots/combat-config.png)

**释放顺序**

从左到右循环执行，默认顺序是 `1, 2, 3, 4, X`。可以拖动释放项调整顺序，也可以右键删除单个动作。

- `追加技能`：快速把 `1`、`2`、`3`、`4` 或 `X` 追加到释放顺序末尾。
- `恢复默认`：恢复默认释放顺序 `1, 2, 3, 4, X`。
- `清空释放顺序`：移除当前释放顺序中的全部动作。

**单回合执行序列**

保存常用按键组合，再将其作为一个动作插入释放顺序。

按键序列写法：

- 用逗号、分号、空格或换行分隔多个步骤，例如 `W, 1, Space`。
- 组合键使用 `+` 连接，例如 `Ctrl+1`。
- 组合键前缀只能使用 `Ctrl`、`Alt` 或 `Shift`。
- 默认每步按键保持 `100ms`，步间间隔 `500ms`，可在“其他配置”中调整。
- 支持 A-Z、0-9、F1-F24、方向键、Space、Enter、Esc、Tab、PageUp、PageDown、Home、End、Insert、Delete 等常用按键。

**保存与取消**

- `保存`：保存本次战斗配置。
- `取消`：放弃本次修改。
:::

::: details 其他配置
打开自动战斗高级时序配置窗口。普通用户建议保留默认值。

- `技能选择基础等待`：进入技能选择后发送按键前等待，默认 `500ms`。
- `污染奇遇额外等待`：第一回合为图鉴精灵名而非幸运惊喜盒时，在基础等待上额外增加的时间，默认 `2500ms`。
- `技能操作重试间隔`：技能选择界面持续未消失时，再次执行同一动作前等待，默认 `4000ms`。
- `按键按下时长`：每个按键从按下到松开的时间，默认 `100ms`。
- `普通按键间隔`：战技和自定义序列相邻按键间等待，默认 `500ms`。
- `捕捉序列按键间隔`：`W, 1, Space` 捕捉序列相邻按键间等待，默认 `500ms`。
:::

## 统计页

![统计页](/screenshots/statistics-overview.png)

### 数据统计

#### 顶部卡片

- 使用账号下拉框切换当前统计账号，也可以在这里添加新的 UID。
- 右键账号项可以删除对应账号及其统计记录。
- 点击 `设置` 可以配置云同步、导入或导出统计数据，以及清空当前记录。

在首页点击“启动”时，应用会从游戏画面的 `uid` 识别区域读取纯数字 UID：

- 已存在的 UID 会直接设为本次任务的自动统计账号。
- 未保存的 UID 会弹窗要求核对，可修改识别结果后确认添加。
- 识别失败或暂不确认时，自动统计会暂停写入，直到在统计页手动选择账号，避免误记到其他账号。
- 需要确认或识别失败时，信息遮罩会在原状态面板顶部显示独立提醒；提醒区域向上扩展，不会压缩状态和计数内容。

#### 异色面板

- 使用面板底部的下拉框筛选全部记录或指定赛季。
- 双击异色条目可以打开详情，在详情窗口中编辑或删除记录；同一精灵有多条记录时，可以使用右侧箭头切换。
- 在异色面板的空白区域点击右键，可以手动新增异色条目。
- 出现待确认异色时，核对精灵名称和奇遇计数后再选择计入或忽略。

::: details 异色详情
![异色详情](/screenshots/statistics-shiny-detail.png)
:::

#### 奇遇面板

- 点击面板左侧右侧的换页图标切换赛季。
- 双击奇遇条目可以打开详情，并对记录进行编辑或删除。
- 在奇遇面板的空白区域点击右键，可以手动新增奇遇条目。

:::: details 云同步配置
![统计云同步](/screenshots/statistics-cloud-sync.png)

统计云同步使用 Cloudflare R2 保存统计数据，适合在多台设备之间同步记录。

**首次配置**

1. 在 Cloudflare 创建 R2 存储桶和具有读写权限的 API 令牌。需要帮助时，可以点击窗口底部的 `教程`。
2. 填写 `Account ID`、`Bucket`、`Access Key ID` 和 `Secret Access Key`。
3. 点击 `保存`，再点击 `测试连接` 确认配置可用。
4. 测试通过后开启 `启用同步`；应用启动时会检查云端更新，后续统计变化会自动上传。

::: tip 推荐顺序
填写配置 → 保存 → 测试连接 → 启用同步
:::

保存已有配置时，`Secret Access Key` 留空会保留原密钥，不需要重复填写。

**云端数据操作**

- `刷新`：重新获取云端数据的更新时间。
- `上传`：检查并合并云端新版本后，立即把当前本地统计上传到云端。
- `合并`：将云端统计合并到本地。
- `关闭`：退出云同步窗口，不会删除已保存的配置。
::::

## 热键页

### 热键配置

![热键页](/screenshots/hotkeys-overview.png)

::: details 信息遮罩窗口
切换信息遮罩窗口的显示或隐藏。
:::

::: details 奇遇统计
切换奇遇统计的启动或停止。
:::

::: details 自动战斗
切换自动战斗的启动或停止。
:::

**设置方式**

- 点击右侧热键按钮后，直接按下新的快捷键即可绑定。
- 设置过程中按 `Esc` 可清除绑定。
- 如果多个功能绑定同一个快捷键，后设置的功能会保留该快捷键，旧功能的重复绑定会被移除。

热键只在目标游戏窗口为焦点时触发。

## 日志页

### 日志查看

![日志页](/screenshots/logs-overview.png)

- 使用 `Debug`、`Info`、`Warn` 和 `Error` 按等级过滤日志。
- 在搜索框中输入关键字，可以筛选日志消息和来源。
- 点击清空按钮只会清空当前页面显示，不会删除日志文件。
- 点击文件按钮可以打开当天日志；当天没有日志时会打开日志目录。

## 设置页

### 应用设置

![设置页](/screenshots/settings-preferences.png)

- `切换主题`：选择跟随系统、浅色或深色主题。
- `日志文件`：在资源管理器中打开日志目录。
- `恢复设置`：清除用户偏好并退出应用，重新启动后生效。
