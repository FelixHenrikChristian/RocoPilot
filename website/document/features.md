# 功能

按应用左侧导航查找功能。每个条目先说明用途和设置位置，截图直接展示当前界面；需要调整参数时，再展开对应的配置细节。首次上手可先看[使用](./use)。

## 启动页

![启动页配置](/screenshots/app/launch-options.png)

### 启动任务

点击“启动任务”卡片右上角的“启动”，开始识别游戏画面，并执行“实时”页已开启的功能。花种挑战和传说精灵也需要先在这里启动。运行后，同一按钮变为“停止”，点击可结束运行。

展开“启动任务”卡片可找到：

| 配置项 | 作用 |
| --- | --- |
| 截图方式 | 决定应用如何获取游戏画面。截图异常时，可更换方式后重新启动。 |
| 按键输入方式 | 决定应用如何向游戏发送按键，供自动战斗和挑战任务使用。 |
| 显示识别区域 | 在游戏画面上显示识别范围，帮助检查画面比例、分辨率和 UI 缩放。 |

::: details 截图方式：可选项与适用情况

| 选项 | 说明 |
| --- | --- |
| Windows Graphics Capture | 使用 Windows 图形捕获获取画面，作为常用选择。 |
| BitBlt | 使用传统 GDI 截图，首选方式获取画面异常时可尝试。 |
| PrintWindow | 尝试通过窗口截图接口获取画面，实际效果取决于游戏窗口是否支持。 |

先停止任务，再切换截图方式并重新启动。运行时保持游戏窗口可见。

:::

::: details 按键输入方式：可选项与驱动准备

| 选项 | 说明 |
| --- | --- |
| Interception | 当前自动操作使用的输入方式，需安装驱动并重启电脑，运行时保持游戏前台。 |
| PostMessage（已失效） | 通过后台窗口消息发送按键，当前游戏中已失效。 |
| SendInput（已失效） | 通过 Windows 前台输入发送按键，当前游戏中已失效。 |

选择 `Interception` 时，未安装驱动会出现引导。具体步骤见[驱动安装](./install#驱动安装)。

:::

### 信息遮罩窗口

“信息遮罩窗口”开关控制悬浮信息的显示。在游戏窗口旁查看最近捕捉和奇遇次数，无需来回切换到统计页。

展开“信息遮罩窗口”卡片可调整位置：

| 配置项 | 作用 |
| --- | --- |
| 锁定位置 | 开启后固定位置；关闭后可拖动窗口。 |
| 重置位置 | 点击“重置”，恢复默认位置。 |

灵动岛用于查看当前游戏状态、战斗动作、捕捉血脉和挑战进度，也会提示待确认账号和异色。

它随“信息遮罩窗口”开关一起显示或隐藏，位置锁定和重置也使用同一卡片中的控件，无需单独开启。

::: details 灵动岛信息

- 顶部显示游戏状态与魔力值。
- 有操作详情时展开，展示技能、回能、捕捉血脉或挑战进度；没有详情时收起。
- 账号需要确认时，提示前往统计页核对 UID。
- 识别到异色时显示保护提示；待确认异色通过标记提醒，可前往统计页处理。

:::

## 实时页

![实时页配置](/screenshots/app/realtime-options.png)

### 奇遇计数

自动累计奇遇次数，按账号和赛季保存记录。打开“奇遇计数”卡片右侧开关即可启用，未启用时不会记录奇遇与异色信息。

需要确认 UID 时，请先到“统计”页核对账号，确认前暂停自动入账。

| 配置项 | 作用 |
| --- | --- |
| 图鉴源 | 选择精灵图鉴的数据来源。 |
| 精灵图鉴 | 查看精灵头像、名称、变种和进化链。 |
| 同步图鉴数据 | 更新本地图鉴，供精灵名称匹配和头像展示使用。 |

::: details 图鉴来源与更新说明

当前图鉴源为 `Biligame 洛克王国世界 Wiki 精灵图鉴`。应用内置本地图鉴，也可点击“同步”更新数据，并查看同步状态。

同步图鉴不会直接把“新赛季”暂存记录归入正式赛季；这部分数据仍需在统计页确认，见[赛季归档](#赛季归档)。

:::

### 自动战斗

根据游戏中的战斗界面自动执行已配置的技能顺序。打开“自动战斗”卡片右侧开关启用；实时识别到异色后，会暂停本场自动操作，玩家须返回游戏手动处理。

花种挑战和传说精灵由“任务”页启动，会执行各自的战斗配置，属独立任务，与实时任务无关，无需开启此开关。

| 配置项 | 作用 |
| --- | --- |
| 奇遇解除操作 | 决定解除奇遇后继续战斗、回能、捕捉，还是等待手动操作。 |
| 战斗配置 | 设置技能顺序、公共按键组合和捕捉血脉筛选。 |
| 其他配置 | 调整技能等待、操作重试和按键节奏。通常保留默认值即可。 |

::: details 奇遇解除操作说明

| 选项 | 行为 |
| --- | --- |
| 无操作 | 奇遇解除后停止按键，等待手动操作。 |
| 回能 | 奇遇解除后按 X 回能，直到退出战斗。 |
| 战技 | 奇遇解除前后均按配置释放技能。 |
| 捕捉 | 奇遇解除后尝试捕捉；启用血脉筛选时按筛选结果处理。 |

:::

#### 战斗配置

入口：**实时 → 自动战斗 → 战斗配置 → 配置**。任务页的花种挑战和传说精灵卡片也各有“战斗配置”入口。

配置窗口将三类战斗的释放顺序分别保存，公共执行序列可以复用。右下角“保存”使修改生效，“取消”放弃本次修改。

**释放顺序**

决定每个回合执行哪些动作（技能、序列等）。

![战斗配置：释放顺序](/screenshots/app/battle-release-order.png)

::: details 释放顺序配置说明

- 点击“添加技能”一行的 `1`、`2`、`3`、`4` 或 `X`，将动作追加到末尾。
- 释放顺序从左到右、逐行循环执行。
- 步骤右侧箭头用于前移或后移，删除按钮移除该步骤；右上角清空按钮移除全部步骤。
- 需要执行按键组合时，在下方“公共执行序列”中选择“添加到末尾”，将整段序列作为一个动作插入。

:::

**公共执行序列**

把常用按键组合保存为可复用的序列，再加入战斗释放顺序。修改公共序列后，已插入的步骤会同步更新。

![战斗配置：公共执行序列](/screenshots/app/battle-shared-sequences.png)

::: details 公共执行序列配置说明

| 配置项 | 作用 |
| --- | --- |
| 新增／创建序列 | 添加一条公共执行序列。 |
| 名称 | 给序列命名，方便在战斗释放顺序中查找。 |
| 按键序列 | 填写需要依次执行的按键，例如 `W, 1, Space`。 |
| 删除按钮 | 删除该公共序列。 |

多个步骤可用逗号、分号、空格或换行分隔。组合键使用 `+`，例如 `Ctrl+1`；组合键前缀支持 `Ctrl`、`Alt`、`Shift`。

:::

**捕捉血脉**

按血脉决定是否捕捉，只在实时自动战斗的“奇遇解除操作”选择“捕捉”时生效。

![战斗配置：捕捉血脉](/screenshots/app/battle-bloodline-filter.png)

::: details 捕捉血脉说明

打开“启用血脉筛选”，勾选希望捕捉的血脉。选中的血脉尝试捕捉，其余按战斗配置释放战技。

可选项为“奇异”“污染”“混血”“普通”和“未识别”。无法读出血脉时，使用“未识别”选项决定是否捕捉；识别依据提示文字，不区分赛季。

:::

#### 其他配置

位置：**实时 → 自动战斗 → 其他配置 → 配置**。用于调整操作节奏，例如进入技能界面后等多久再按键、多久重试一次。只有观察到操作节奏不合适时才需要调整。

::: details 战斗时序与按键时序说明

以下时间单位均为毫秒。

| 分组 | 配置项 | 作用 |
| --- | --- | --- |
| 战斗时序 | 技能选择基础等待 | 进入技能界面后，执行操作前的等待时间。 |
| 战斗时序 | 技能操作重试间隔 | 技能界面未消失时，再次执行动作的等待时间。 |
| 按键时序 | 按键按下时长 | 每个按键从按下到松开的时间。 |
| 按键时序 | 普通按键间隔 | 战技与自定义序列中相邻按键的间隔。 |
| 按键时序 | 捕捉序列按键间隔 | 捕捉操作中相邻按键的间隔。 |

:::

## 任务页

先在“启动”页点击“启动”，再选择要运行的任务。扫描和挑战一次运行一个，期间暂停实时识别，结束后恢复。

### 花种挑战

自动选择目标花种，连续挑战、战斗并捕捉，完成设定次数后结束。

![任务页：花种挑战](/screenshots/app/flower-seed-options.png)

| 配置项 | 作用 |
| --- | --- |
| 目标花种 | 选择要挑战的花种；右侧扫描按钮用于从游戏获取花种列表。 |
| 战斗次数 | 设置希望成功捕捉的次数。 |
| 战斗配置 | 设置花种战斗的动作序列。 |
| 启动／停止 | 开始挑战，或取消当前任务。 |

### 传说精灵

自动前往目标精灵，完成挑战准备、战斗与捕捉。

![任务页：传说精灵](/screenshots/app/legendary-options.png)

| 配置项 | 作用 |
| --- | --- |
| 目标精灵 | 选择要挑战的精灵，右侧刷新按钮可从游戏获取名单。 |
| 挑战难度 | 指定本次挑战使用的难度。 |
| 战斗次数 | 设置希望成功捕捉的次数。 |
| 使用传说印记 | 决定体力或周捕捉次数不足时，是否使用传说印记继续。 |
| 战斗配置 | 设置传说精灵战斗的技能释放顺序。 |
| 启动／停止 | 开始挑战，或取消当前任务。 |

::: details 传说精灵配置说明

- **目标名单**：刷新后的名单和选择仅本次应用启动有效。
- **挑战难度**：可选“难度I”“难度II”“难度III”，开始挑战前自动选择指定难度。
- **战斗次数**：可设为 1–99，按成功捕捉累计，连续失败 3 次后停止。
- **使用传说印记**：开启后在体力或周捕捉次数不足时使用；关闭后遇到不足提示即停止。
- **缺少专属印记**：缺少捕捉所需专属印记时，会退出挑战并提示。

启动前请核对资源消耗。流程会跳过可跳过的动画。

:::

## 统计页

![统计页](/screenshots/app/statistics-overview.png)

### 统计账号

按 UID 分开管理各账号记录。点击顶部账号选择按钮可以切换要查看的账号；列表底部“添加账号”用于新增 UID，右键账号项可删除该账号及其记录。

需要确认账号时，顶部会出现 UID 提醒。确认前暂停自动入账，避免把记录记到其他账号。

::: details UID 确认与账号切换规则

启动时已开启计数，或运行中开启计数时，应用会读取游戏 UID。与当前已选 UID 一致时直接使用；新 UID、不同 UID 或识别失败时需要核对。

点击 UID 提醒图标，可选择“重新识别并确认”或“手动确认账号”；待确认时，也可以点击正确的已有账号完成确认。

自动统计绑定本次确认的账号，平时切换账号只改变浏览对象。切换游戏账号后，应停止并重新启动任务，再核对 UID。

:::

### 记录管理

异色面板用于查看捕获记录，奇遇卡片用于查看各赛季的累计次数，异色卡片记录各赛季异色情况。

当实时任务的奇遇统计识别到异色精灵时，需要进入统计页进行手动确认，确认捕获后保存异色，并清零对应奇遇累计。

| 入口或操作 | 作用 |
| --- | --- |
| 异色面板底部下拉框 | 按赛季筛选异色记录。 |
| 奇遇卡片左右换页按钮 | 切换要查看的赛季奇遇。 |
| 双击记录 | 打开详情，编辑或删除该记录。 |
| 面板空白区域右键 | 手动新增记录。 |
| 设置 → 导出数据 | 备份统计记录。 |
| 设置 → 导入数据 | 从统计文件恢复或导入记录。 |
| 设置 → 清空记录 | 清空统计，请先导出重要数据。 |

#### 赛季归档

软件内赛季配置到期后，新记录先进入“新赛季”暂存。更新软件或同步图鉴后，使用统计页顶部的“确认新赛季统计”，核对记录应归属的赛季。

::: details 新赛季记录确认与归档说明

- 临时奇遇按日期累计，页面按精灵展示；未精确匹配图鉴时保留原始识别文字。
- 临时异色仍需先确认捕获，确认后清零对应临时奇遇次数。
- 归档窗口按“精灵＋建议赛季”分组，奇遇可修改名称、次数和目标赛季；次数填 0 可清理该组。
- 已捕获异色逐只核对名称和赛季。归档不会再次清零奇遇。
- 选择要处理的数据并确认后，移除对应暂存；未处理的继续保留。

:::

#### 数据同步

通过 Cloudflare R2 存储桶在多台设备间同步统计。入口：**统计 → 设置 → 云同步**。

**连接配置**

填写存储桶与令牌信息，点击“保存配置”后使用“测试连接”检查是否可用。窗口底部“教程”介绍 R2 的准备步骤。

![云同步：连接配置](/screenshots/app/statistics-cloud-sync.png)

::: details 连接配置：各字段的作用

| 配置项 | 作用 |
| --- | --- |
| 同步方式 | 当前使用 Cloudflare R2。 |
| Account ID | Cloudflare 账户 ID，用于连接对应账户的 R2。 |
| Bucket | 保存统计文件的存储桶名称。 |
| Access Key ID | R2 API 令牌的访问密钥 ID。 |
| Secret Access Key | 与访问密钥 ID 配套的密钥；已有配置时留空会保留原值。 |
| 保存配置 | 保存当前连接信息，修改后应先保存再测试或同步。 |
| 测试连接 | 检查已保存配置能否连接存储桶。 |

:::

**同步与数据**

开启“自动同步”后，本地统计变化会自动上传。换设备前请确认上传完成，“待上传”表示本地修改尚未成功上传。

![云同步：同步与数据](/screenshots/app/statistics-cloud-actions.png)

| 配置项 | 作用 |
| --- | --- |
| 检查云端时间 | 查看云端更新时间，不下载或合并数据。 |
| 上传到云端 | 先检查云端并处理账号版本，再上传本地统计。 |
| 合并云端数据 | 将云端账号记录同步到本地，有冲突时核对选择。 |
| 自动同步 | 本地变化后延迟自动上传，应用启动时检查云端。 |

::: details 多设备同步：冲突处理与数据变更

同一账号两端各自修改时，会停止本次同步并保留双方数据。点击“上传到云端”或“合并云端数据”，在冲突窗口核对后选择“保留本地”或“采用云端”。

选择以整个账号为单位，另一端独有内容不会自动相加。可以先取消，返回统计页分别导出备份或整理记录。

删除账号、减少次数和清零也会同步。所有设备都应使用支持当前同步机制的版本，失败原因可在同步状态和日志中查看。

:::

## 热键页

### 热键绑定

为信息遮罩窗口、奇遇统计和自动战斗设置快捷开关，实时任务运行且游戏在前台时生效。每行左侧是功能，右侧是当前绑定的热键。

![热键绑定](/screenshots/app/hotkeys-overview.png)

点击对应行右侧按钮，按下要绑定的快捷键；录入时按 `Esc` 清除绑定。

如果同一快捷键已绑定其他功能，后设置的功能会保留它，旧功能的重复绑定会被移除。

## 通知页

### 系统通知

接收任务结果和实时异色提醒。位置：**通知 → 通知设置**。

![通知设置](/screenshots/app/notifications-overview.png)

| 配置项 | 作用 |
| --- | --- |
| Windows 通知 | 控制是否发送任务结果与实时异色提醒。 |
| 通知提示音 | 控制通知是否使用系统默认提示音。 |
| 测试通知 | 发送测试消息，检查显示和声音是否正常。 |

## 日志页

### 日志诊断

查看应用运行时的识别、按键、任务与同步信息，帮助定位问题。顶部工具栏用于筛选和打开日志文件。

![日志筛选](/screenshots/app/logs-overview.png)

| 条目 | 作用 |
| --- | --- |
| Debug、Info、Warn、Error | 选择要显示的日志等级。 |
| 搜索框 | 按关键字筛选日志消息和来源。 |
| 清空图标 | 清空当前页面显示，文件日志不受影响。 |
| 文件图标 | 打开当天日志；当天没有文件时打开日志目录。 |

调整应用外观、管理日志、检查版本更新和打开项目链接。

![应用设置](/screenshots/app/settings-overview.png)

| 条目 | 作用 |
| --- | --- |
