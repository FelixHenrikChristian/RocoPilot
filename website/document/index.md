# 介绍

RocoPilot 是面向《洛克王国：世界》的 Windows 桌面辅助工具，主要用于实时识别游戏画面、记录奇遇次数、辅助自动战斗和管理统计数据。

## 主要功能

- `奇遇计数`：按赛季记录各精灵的奇遇次数。异色待用户确认后计入统计。
- `自动战斗`：识别战斗界面后，按配置自动释放技能或执行自定义按键序列。
- `统计管理`：按账号查看、编辑、导入、导出奇遇和异色数据。
- `图鉴数据`：同步精灵图鉴，查看头像、编号、变种和进化链。
- `信息遮罩`：在游戏窗口旁显示运行状态、计数和识别结果。
- `热键切换`：通过快捷键快速切换常用功能。
- `日志信息`：查看截图、OCR、识别、按键和云同步相关日志。

## 使用建议

- 图像识别支持 16:9 和 4:3 画面比例。素材基准分辨率分别为 `2048×1152` 和 `1920×1440`，理论上可适配相同画面比例下的其他分辨率；若识别效果不佳，建议切换至对应的素材基准分辨率。
