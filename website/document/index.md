# 介绍

RocoPilot 是面向《洛克王国：世界》的 Windows 桌面辅助工具，提供自动战斗、奇遇计数、花种挑战和传说精灵等功能，支持异色记录、赛季归档及多设备数据同步。

## 主要功能

| 功能 | 能力 |
| --- | --- |
| 自动战斗 | 设置技能顺序、公共按键序列、奇遇解除操作和捕捉血脉筛选。 |
| 奇遇计数 | 按账号、赛季记录奇遇，确认异色后保存记录，支持新赛季暂存与归档。 |
| 花种挑战 | 扫描并选择目标花种，按设定次数自动挑战与捕捉。 |
| 传说精灵 | 选择目标、难度、次数和印记策略，自动挑战与捕捉。 |

## 辅助功能

为战斗、挑战和统计提供状态展示、操作提醒与数据管理支持。

| 功能 | 能力 |
| --- | --- |
| 信息遮罩 | 在游戏窗口旁展示最近捕捉和奇遇次数。 |
| 灵动岛 | 展示游戏状态、战斗动作、捕捉血脉、任务进度与重要提醒。 |
| 精灵图鉴 | 查看头像、编号、变种和进化链，同步图鉴数据。 |
| 数据同步 | 导入导出备份，使用 Cloudflare R2 同步多设备统计，核对账号冲突。 |
| 系统通知 | 接收任务结果与实时异色截图提醒，支持提示音。 |
| 热键绑定 | 快捷切换信息遮罩、奇遇计数和自动战斗。 |
| 日志诊断 | 按等级和关键字查看识别、按键、任务及同步日志。 |
| 自动更新 | 在设置页检查新版本，通过更新器或安装包升级。 |

## 页面入口

| 左侧导航 | 在这里做什么 |
| --- | --- |
| 启动 | 启动或停止运行，设置截图与输入方式，控制信息遮罩和灵动岛。 |
| 实时 | 开启奇遇计数、同步图鉴，设置并开启自动战斗。 |
| 任务 | 选择并启动花种挑战或传说精灵。 |
| 统计 | 核对账号、查看记录、确认异色、归档新赛季数据、配置云同步。 |
| 日志 | 筛选运行日志，打开日志文件。 |
| 热键 | 绑定各功能的快捷键。 |
| 通知 | 开启系统通知、提示音并发送测试通知。 |
| 设置 | 调整主题、打开日志目录、恢复设置、检查更新。 |
