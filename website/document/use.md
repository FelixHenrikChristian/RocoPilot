# 使用

::: tip 权限
RocoPilot 默认会以管理员方式启动。这样可以减少截图、窗口识别和按键输入因为权限不足而失败的情况。
:::

本页按常见顺序说明软件的使用流程。

## 1. 启动实时任务

![启动页](/screenshots/launch-overview.png)

打开目标游戏窗口后，进入 `启动` 页点击 `启动`。启动成功后，RocoPilot 会持续获取游戏窗口画面并进行识别。

首次使用时，如果需要确认截图方式、OCR 或识别区域，可以展开“启动任务”进行检查。具体配置见 [功能 - 启动任务](./features#启动任务)。

## 2. 调整信息遮罩

“信息遮罩窗口”用于显示当前运行状态、奇遇计数、识别结果和待确认异色提示。默认位置在游戏窗口右侧。

如果遮罩挡住游戏画面，可以先关闭锁定，拖到合适位置后再重新锁定。

## 3. 开启实时功能

![实时页](/screenshots/realtime-overview.png)

进入 `实时` 页，根据需要打开 `奇遇计数` 或 `自动战斗`。

首次使用`奇遇计数`前，建议先同步图鉴数据，以免漏识别新精灵。

首次使用`自动战斗`前，建议先和普通精灵战斗测试是否正常，以免误操作稀有精灵。

实时功能的详细配置见 [功能 - 奇遇计数](./features#奇遇计数) 和 [功能 - 自动战斗](./features#自动战斗)。

## 4. 查看统计数据

![统计页](/screenshots/statistics-overview.png)

进入 `统计` 页查看异色统计和当前赛季奇遇次数。

顶部可以`切换账号`，设置菜单中可以`导入`、`导出`、`清空`记录或配置`云同步`。

识别到异色后，RocoPilot 会先显示待确认窗口。确认前可以修正精灵名和当前奇遇计数。

## 5. 配置使用热键

![热键页](/screenshots/hotkeys-overview.png)

进入 `热键` 页可绑定信息遮罩、奇遇统计和自动战斗的开关。

热键只在实时任务运行，并且目标游戏窗口为焦点时触发。

## 6. 查看日志信息

![日志页](/screenshots/logs-overview.png)

进入 `日志` 页可以查看运行时日志，并进行筛选，方便排查运行中遇到的相关问题。
